🚀 Getting Started — Step by Step

Follow these steps in order. Each step assumes you completed the previous one.

1

Install the toolkits

From the repo root, run the installer. This copies all toolkit modules to your user Modules folder and wires up your profile.

.\Install-Toolkit.ps1 -AutoLoad -Verify
2

Reload PowerShell (or your profile)

Close and reopen PowerShell, or run:

. $PROFILE
3

Optional: create a profile for remote targets

Profiles are only needed for remote/target-specific actions. For local actions, you can skip this and run commands directly. Create a profile when you need to target a remote machine or service.

# SSH target (SSHToolkit) New-Target -Name server1 -IP 10.0.0.50 -User admin -Key 'C:\keys\id_rsa' # Docker host (DockerToolkit) Register-DockerProfile -Name swarm -Host tcp://10.0.0.10:2376 # Cloud (CloudToolkit) Register-CloudProfile -Name aws-prod -Provider aws -Region us-east-1 -Profile default # Git workspace (GitToolkit) Register-GitProfile -Name work -Path 'C:\Projects' -User 'you' -Email 'you@example.com'
4

Run actions directly (no profile needed)

All actions are available as direct commands. Local actions like sys, speak, and beep run on the local machine by default.

sys # Expected: hostname, OS, CPU, RAM, uptime, free disk speak 'Hello world' # Expected: speaks text aloud (alias: say, tts, voice) beep # Expected: system beep tone registry # Expected: list of all installed toolkits
5

Run actions through a profile (remote targets)

When you need to target a remote machine, prefix the action with your profile alias.

server1 sys # Expected: hostname, OS, CPU, RAM, uptime, free disk (remote) server1 help # Expected: full index of builtins, actions, listeners, chains server1 banner # Expected: permanent legend/status box for that profile
6

Enable tab completion (if not auto-loaded)

Tab completion is registered automatically by the installer. If it is not working:

Initialize-ToolkitCompletion
7

Explore every part of every toolkit

Use the sections below to see exact commands and expected output for every toolkit. Commands work both directly and through profile aliases.
