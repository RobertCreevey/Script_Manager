🚀 Getting Started — Step by Step

Follow these steps in order. Each step assumes you completed the previous one.

1

Install the toolkits

From the repo root, run the installer. This copies all toolkit modules to your user Modules folder and wires up your profile.

.\Install-Toolkit.ps1 -AutoLoad -Verify
2

Reload PowerShell (or your profile)

Close and reopen PowerShell, or run:

. $PROFILE
3

Create your first profile

Profiles are target configs that become shell aliases. Pick the right command for your target type.

# SSH target (SSHToolkit) New-Target -Name server1 -IP 10.0.0.50 -User admin -Key 'C:\keys\id_rsa' # Docker host (DockerToolkit) Register-DockerProfile -Name swarm -Host tcp://10.0.0.10:2376 # Cloud (CloudToolkit) Register-CloudProfile -Name aws-prod -Provider aws -Region us-east-1 -Profile default # Git workspace (GitToolkit) Register-GitProfile -Name work -Path 'C:\Projects' -User 'you' -Email 'you@example.com'
4

Verify your profile alias works

Your profile name is now a global alias. Test it:

server1 help # Expected: full help index for that profile
5

Try your first action

Every profile supports sys, help, and banner out of the box.

server1 sys # Expected: hostname, OS, CPU, RAM, uptime, free disk server1 banner # Expected: permanent legend/status box server1 help # Expected: full index of builtins, actions, listeners, chains
6

Enable tab completion (if not auto-loaded)

Tab completion is registered automatically by the installer. If it is not working:

Initialize-ToolkitCompletion
7

Explore every part of every toolkit

Use the sections below to see exact commands and expected output for every toolkit.
